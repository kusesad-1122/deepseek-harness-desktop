# DSH Desktop v2.0.21 更新公告

**安装包**：[DSH-Desktop-2.0.21-x64-Setup.exe](https://github.com/kusesad-1122/deepseek-harness-desktop/releases/download/v2.0.21/DSH-Desktop-2.0.21-x64-Setup.exe)（Windows x64）
**SHA256**：`9c0f59bdf73cc521b3bf21e361b87c606d3fafce4b448fb3b3c83299cf64f71c`

## 本版本重点

### 1. 扩展面板改为可点击项目

- 扩展面板首页现在显示五个独立项目：对话、知识卡、每日热点新闻、知识图谱、专家风格模式。
- 点击项目后进入独立页面，标题栏提供返回入口，不再把全部功能堆在同一页。
- 知识卡进入后才显示搜索、详情、刷新与删除。
- 专家风格模式进入后才显示平衡、严谨、创意、简洁、深度五种选择。

### 2. 每日热点新闻与知识图谱彻底分离

- “每日热点新闻”使用固定公共新闻简报源，显示当天热点条目，可刷新并打开完整简报。
- 新闻请求不包含用户数据；Host 端设置 8 秒超时、15 分钟缓存，并限制最多 20 条。
- “知识图谱”只展示知识卡之间的标签关系，节点和知识卡均可点击查看详情。
- 不再把知识卡伪装成新闻，也不再使用“新闻与知识图谱”这个混合名称。

### 3. 记忆与知识桥接修复

- Agent 侧 memory/knowledge 插件使用明确的桌面 loopback Web 地址。
- Node 运行环境下为写操作补充同源 Origin；浏览器环境继续使用浏览器自己的 Origin。

## 升级方式

- 已安装用户：托盘菜单中的 Check for Updates；或直接下载安装包覆盖安装。

## 已知问题

- 本版本只发布 Windows x64 安装包。
- 当前 Windows 发布流程生成未做 Authenticode 签名的安装包；文件完整性以本页 SHA256 为准。
- 每日热点新闻依赖外部固定新闻源；源不可用时界面会显示明确的重试状态。

## English

**What's new in 2.0.21**

- The extended panel is now a project navigator with focused, clickable views.
- Daily Hot News and the Knowledge Graph are separate projects with separate data semantics.
- Knowledge Cards and Expert Style Mode open dedicated interactive views.
- Agent-side memory and knowledge bridges use an explicit same-origin loopback route client.

**Known issues**

- Windows x64 only; the installer is unsigned by Authenticode.
- Daily Hot News depends on a fixed external public feed and exposes a retry state when unavailable.
