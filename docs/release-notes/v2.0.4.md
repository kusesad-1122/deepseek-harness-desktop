## 本版本重点：检查更新与更新安装体验升级

本次更新学习了 Hermes Desktop 的更新交互设计，在原有托盘检查 + 原生确认框的基础上，把整个流程补齐：

### 1. 更新公告直接可见

- 检查到新版本时，确认对话框直接显示该版本的 GitHub Release 更新公告；
- 新增 **Release Notes** 按钮，点击后用默认浏览器打开完整公告页面；
- 没有公告时保持简洁的两按钮确认，不显示占位文案。

### 2. 下载进度可见

- 下载安装包时，托盘状态实时显示百分比：
  `Downloading DSH Desktop 2.0.4… 42%`。

### 3. 失败不再静默

- 下载失败或安装器启动失败时，弹出原生通知 **DSH Desktop Update Failed**，附带失败原因；
- Windows 安装器启动后增加短暂观察窗口：如果进程立刻退出或启动失败，**应用不会退出**，你可以直接重试，不再出现“窗口关了、安装器没出现”的情况。

### 4. 发布流程升级（面向维护者）

- 每个版本发布前必须准备 `docs/release-notes/<tag>.md` 用户向更新公告；
- CI 会在公告缺失时拒绝发布，从流程上保证“发版必带公告”。

### 变更摘要

- 版本 2.0.3 → **2.0.4**
- `feat(updates)`: 公告展示、进度百分比、失败通知、安装器交接可靠性
- `ci(release)`: 发布公告强制门禁
- `docs`: 更新 UX 说明与公告模板

## 升级方式

- **已安装用户**：托盘 → Check for Updates… 立即检查；或等待后台自动检查（启动约 1 分钟后，之后每 6 小时一次）；
- **全新安装**：直接下载上方安装包。

## 已知问题

- 本版本暂只发布 **Windows x64** 安装包；macOS 构建流水线尚未随本次发布提供，mac 用户请等待后续版本；
- 本地 Windows 全量测试存在一个既有的 POSIX 文件权限断言失败（`0600` vs `0666`），与本次改动无关；CI 发布门禁 `check:win-package` 已完整通过。

## English

**What's new in 2.0.4**

- Update announcements are now shown inside the confirmation dialog, with a **Release Notes** button opening the full release page.
- Download progress streams into the tray label with a live percentage.
- Download and installer-handoff failures surface a native **DSH Desktop Update Failed** notification instead of failing silently.
- The Windows installer hand-off is observed before the app exits, so a failed launch keeps the app running and lets you retry.
- Releases now require a user-facing announcement file; CI refuses to publish without it.

**Known issues**

- Windows x64 installer only in this release.
- One pre-existing Windows-only POSIX mode assertion in the local full test suite; the CI packaging gate passes.
