## 🧠 记忆必带（Memory Must-Always-Be-Present）

之前发现：不同 agent 预设（`router-standard`、`minimal`、`grayscale`…）会**过滤工具、替换提示词段**，导致 `memory` 工具和记忆提示词只在部分预设/项目里出现。上一版靠手动改预设才让你的默认预设生效——这次把它做成**应用层强制**：

- 无论任何预设怎么过滤，**最终组装完成后，`memory` 工具和记忆提示词段都会被强制放回**；
- 这意味着：**任何项目、任何预设、任何会话，开局必有记忆**——不用再逐个预设手工补丁；
- 和 v2.0.15 的渲染进程插件（memory-web）+ 宿主存储配合，形成完整的「写入 → 落盘 → 全局注入」闭环。

## 验证方式

1. 升级到 2.0.16，重启 DSH Desktop；
2. 随便开几个**不同项目/预设**的会话，问「你有没有 memory 工具？我是什么样的人？」；
3. 每个会话都应有 `memory` 工具，且能答出你的画像/之前聊过什么。

## What's new in 2.0.16

- Added an app-layer `system-prompt/assemble` listener in the renderer memory plugin that, after any preset's assembly filtering, forcibly re-adds the `memory` tool (from the live tools registry) and the dynamic memory prompt section. Memory is now present in **every** project/preset/session regardless of preset tool filtering or complete-persona section replacement.
