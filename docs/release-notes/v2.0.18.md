# DSH Desktop v2.0.18 更新公告

**安装包**：[DSH-Desktop-2.0.18-x64-Setup.exe](https://github.com/kusesad-1122/deepseek-harness-desktop/releases/download/v2.0.18/DSH-Desktop-2.0.18-x64-Setup.exe)（Windows x64）
**SHA256**：`待回填`

## 🧠 默认开袋：左侧扩展区任何模式都显示

v2.0.17 的左侧扩展区只在「高级模式」显示；这版把它做成**默认（兼容模式）就出现**——无需切换高级模式。

- 通过 `shell.overlay` 槽做**固定定位左 dock**（300px，可折叠成 56px 图标栏，状态持久化到 localStorage `dsh-desktop.compat-extended`）；
- app 自动向右偏移 dock 宽度；
- 高级模式原路径未变（`apply()` 严格按 mode 分支，不会双挂载）；
- 四个板块全部可用：**对话 / 知识卡 / 新闻与知识图谱 / 专家风格模式**。

## 验证方式

1. 升级 2.0.18，重启 DSH Desktop；
2. 直接打开（无需切高级模式）—— 左侧出现 300px 扩展区 dock；
3. `«` 折叠成 56px 图标栏，再次点击展开，重启后保留选择。

## 已知下版本补（v2.0.19）

- 全局思考强度下拉框：让任何自定义 provider/模型自动出现 `low/high/xhigh/max` 选项（v2.0.17 的 `reasoning-default` 仅作用于请求，不影响模型选择器 UI）；
- 新闻路由 `GET /dsh-desktop/knowledge/news`（新闻板块当前优雅降级）。

## What's new in v2.0.18

- Default left extended panel in compatibility mode (via `shell.overlay` fixed-position dock, 300px, icon-rail collapse, persisted choice). Advanced mode untouched. No double-mount.
