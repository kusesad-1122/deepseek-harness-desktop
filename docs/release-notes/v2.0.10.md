## ⚠ 修复「更新中」弹窗全黑 + 原生样式

上一版把「有更新 / 更新中 / 装好重启」做成了 Hermes 风格自绘弹窗，但**下载进度弹窗有个 bug：点「立即更新」后出现的进度窗是全黑的，什么都没有，而且窗口还带着 Windows 原生标题栏**。这版修复：

### 1. 进度窗不再全黑（根因）

- 进度窗走的是 `progress()` 通道，它直接调 `__updateProgress()`，而该函数有个守卫“只有先经过 `__render` 的 `progress` 阶段才渲染”——进度窗从来没跑过 `__render`，于是**进度 UI 永远不渲染**，只剩深色背景 = 全黑。
- **修复**：首次调用进度更新时自动完成进度 UI 的初始渲染（阶段、进度条、百分比、取消按钮），后续更新原地刷新进度条；
- 同时进度调用现在**先等页面加载完成**再注入脚本，消除“脚本跑在页面加载前导致空白”的竞态。

### 2. 弹窗不再长成原生 Windows 样子

- 弹窗改为**无边框自绘**（`frame: false`），带自定义可拖动标题栏和 ✕ 关闭按钮，配色保持 Hermes 深色终端质感（琥珀进度条 / 米白文字 / 深棕背景），和 v2.0.7 的「更新可用」弹窗统一。

### 3. 其它

- 下载进度窗的 ✕ 和「取消」现在能正常关窗（后台下载继续，完成后仍会弹「重启安装」）；关闭后再点不会报错；
- 弹窗创建/驱动失败仍自动回退到原生对话框，绝不卡死更新流程。

## 验证方式

1. 升级到 2.0.10；
2. 等自动提示或点 设置 → 关于 → 检查更新；
3. 有新版 → 点「立即更新」→ 现在能看到琥珀色的下载进度窗（阶段 + 百分比 + 动画条），不再是黑窗；
4. 下载完成 → 「安装已就绪」→ 点「立即重启安装」完成升级。

## What's new in 2.0.10

- Fixed the black "downloading" update dialog: the progress phase never rendered because `__updateProgress` early-returned when the phase had not been primed by `__render`; first progress call now mounts the progress UI itself, and `progress()` waits for the page load before injecting.
- Made the styled update window frameless with a custom draggable title bar and ✕ close button (no native Windows chrome); ✕ / 取消 on the progress window now dismiss it cleanly while the background download continues.
