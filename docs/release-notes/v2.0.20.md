# DSH Desktop v2.0.20 更新公告

**安装包**：[DSH-Desktop-2.0.20-x64-Setup.exe](https://github.com/kusesad-1122/deepseek-harness-desktop/releases/download/v2.0.20/DSH-Desktop-2.0.20-x64-Setup.exe)（Windows x64）
**SHA256**：`81aee85ceb3866c6d57c8bdbce50ca61f06836a446db4d64647b9a798fd2e8d0`

## 本版本重点

### 1. 新闻与知识图谱真正接通

- 实现 `GET /dsh-desktop/knowledge/news`。
- 新闻板块现在从知识库读取最新卡片，并返回 `id`、`title`、`summary` 与发布时间。
- 此前客户端已具备展示逻辑，但 Host 端路由缺失；本版本补齐该实际缺口。

### 2. 自定义模型的思考强度默认能力

- 对桌面实际安装的 `@deepseek-ai/dsh-llm-pi-ai@0.1.0-rc.6` 应用运行时补丁：未声明 `reasoningEfforts` 的手写模型默认提供 `off`、`low`、`high`、`xhigh`、`max` 档位。
- 显式声明 `reasoningEfforts: false` 的模型仍保持无推理能力。

### 3. 重新验证 Windows 安装包

- 发布前执行 `check:win-package`、NSIS 打包和安装包验证。

## 升级方式

- 已安装用户：托盘菜单中的 Check for Updates；或直接下载上方 Windows x64 安装包覆盖安装。
- 若升级后仍看不到左侧扩展区，请在设置中确认桌面模式为兼容模式并完整重启应用；该问题需要附带运行期 Console 日志继续定位。

## 已知问题

- 本版本只发布 Windows x64 安装包。
- 当前 Windows 发布流程生成未做 Authenticode 签名的安装包；文件完整性以本页 SHA256 为准。
- 左侧扩展区代码已被编入客户端 bundle；若完整重装后仍未出现，需要基于运行期日志继续排查，而不是再把未验证结论写进发布说明。

## English

**What is new in 2.0.20**

- The knowledge-news endpoint is now implemented and serves the newest knowledge cards.
- Hand-declared custom models receive the default reasoning-effort capability map.
- The Windows installer is built and verified before publication.

**Known issues**

- Windows x64 only.
- The installer is unsigned by Authenticode; verify it with the SHA256 above.
- If the extended left panel is still absent after a full reinstall, runtime Console diagnostics are required to identify the remaining renderer issue.
