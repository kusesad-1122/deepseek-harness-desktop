## 🔄 侧边栏「检查更新」按钮

侧边栏底部新增 **「检查更新」** 按钮（折叠成窄栏时是 ↻ 图标）：

- **点击立即手动检查**，与托盘 Check for Updates 走同一流程——有新版就弹 v2.0.7 那个 Hermes 风格更新窗，没有就提示已是最新；
- **自动检查照常**：应用仍每 6 小时 + 启动 60 秒后后台自动查（只查你的 fork `kusesad-1122/deepseek-harness-desktop`），手动/自动并存。

## 🧠 记忆面板文案修正

「（空）」提示不再写模糊的“N 轮”，而是显示真实轮数：

> （空）— 每 **4** 个用户回合的自动复习后写入第一条记忆（忽略 ok/继续 等平凡回合）

即 `reviewInterval = 4`：非平凡的第 4 个用户回合结束后后台复习，摘出有价值内容写入 MEMORY.md / USER.md。

## 验证方式

1. 升级到 2.0.8；
2. 侧边栏底部看到「检查更新」，点一下即手动检查（托盘里也有同款入口）；
3. 设置 → 记忆 面板的空态提示会显示“每 4 个用户回合”。
