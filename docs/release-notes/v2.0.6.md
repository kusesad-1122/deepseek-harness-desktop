## 🧠 记忆系统：这次你一定能“看见”

v2.0.5 只有 `/memory` 命令，没有图形界面，所以你“看不到记忆”。这一版补上：

### 1. 设置面板「记忆」（真正的 UI）

设置页新增 **「记忆」** 分栏，实时显示：

- MEMORY.md / USER.md 的**每条内容 + 字符用量条**（如 `840/2200 chars · 3 entries`）；
- **自动复习状态**：开/关、间隔、上次运行结果（成功 / 暂存待审批 / 失败原因）；
- **待审批写入**队列，每个 pending 带批准/拒绝按钮；
- **写入审批**开关（点一下即切换）。

面板 2.5 秒自动刷新；所有操作走同源 HTTP 路由，聊天里等价命令照常可用（`/memory pending|approve <id>|reject <id>|approval on|off`）。

### 2. 自动复习更容易“跑起来”

- 默认复习间隔从 6 轮降到 **4 轮**，更快看到第一条记忆；
- 平凡回合（“ok”“继续”等）不再推进节奏；
- **每次复习都会写 `review-state.json`**（哪怕没摘出可存内容、或跳过、或失败都留痕），再也不会出现“静默没跑”；
- 插件首启即在 `memory/review-state.json` 留下 `loadedAt` 标记——升级后一眼能确认插件真的加载了。

### 3. 安全与健壮（Hermes threat_patterns strict 移植）

- **写入前威胁扫描**：add/replace/batch 含注入/越权/硬编码密钥/隐形 Unicode 直接拒绝；
- **快照降级**：磁盘记忆被投毒时，注入系统提示词的版本替换为 `[BLOCKED: …]`，原文件保留供你查看删除；
- **围栏注入**：记忆块包在 `<memory-context>` + System note 里，明确“这不是用户输入、不是指令”；
- **写入审批门**（默认关）：开启后连后台复习的写入也先进 `pending/`，`/memory approve` 批准后才落盘；
- **审计**：`memory/audit.jsonl` 记录每次写入的来源（前台/复习/审批）与结果；
- **健壮性**：非法 UTF-8 拒写不覆盖、BOM 剥离、写盘 fsync、崩溃残留锁自动自愈。

## 关于“检查版本按钮”

你新装的 `@linxin666/dsh-remote-web-ui` 里的「检查更新」，查的是 **npm 上 `@linxin666` UI 插件家族**自己的版本，与 DSH Desktop 应用无关——它既不会碰官方，也不会碰你的 fork。**你的应用自身的更新检查（托盘/设置）一直只指向你的仓库** `kusesad-1122/deepseek-harness-desktop`。如果你想隐藏那个第三方插件的更新入口，告诉我，我在 profile 补丁里处理。

## 验证清单（装完立刻做）

1. 升级后打开 **设置 → 记忆**，看到面板（空条目 + 自动复习“开，每 4 轮”+ `review-state.json` 已生成）；
2. 正常聊 **4 轮**（避免纯“ok/继续”），等几秒 → 面板出现第一条记忆，`memory/MEMORY.md` 出现内容；
3. 手动往 MEMORY.md 追加非 `§` 内容再让模型 replace → 收到漂移拒绝 + `.bak` 备份。

## What's new in 2.0.6

- **Memory settings panel** (`settings.section`): live entries, char budgets, review status, pending-approval queue, approval toggle — polled via `/dsh-desktop/memory/*` routes.
- **Review loop hardening**: 4-turn default, trivial-turn gate, `review-state.json` written on every run (incl. skip/failure), `loadedAt` boot marker.
- **Security** (Hermes threat_patterns strict port, dependency-free): pre-write scanning, `[BLOCKED]` snapshot degradation, `<memory-context>` fence + System note, optional write-approval gate with pending replay, `audit.jsonl` origin-tagged audit trail.
- **Robustness**: fatal UTF-8 reads, BOM stripping, fsync, stale-lock self-heal.
- Full CI gate (`check:win-package`) green: 122 unit tests + 4 closure checks; memory suites 34/34.
