## ⚠ Hermes 风格更新弹窗

这版把「有更新提示」和「更新中」都换成了 Hermes 风格的深色终端质感弹窗（自绘窗口，不再依赖系统对话框）：

### 「更新可用」弹窗
- 顶部黄色 **⚠ DSH Desktop 更新可用** 横幅；
- **`v当前版 → v新版`** 版本对比（旧版划线）；
- **发布公告预览**（取公告前 1200 字符，滚动查看）；
- 三个按钮：**立即更新**（主） / **查看公告**（浏览器打开 Release 页） / **稍后**。

### 「更新中」弹窗
- 深色进度窗，**阶段行 + 动画进度条 + 百分比**（`下载中 … 42%` → `校验中 100%`）；
- 下载完成自动切换到「✓ 安装已就绪」，提供 **立即重启安装** / **稍后**。

### 兜底
- 弹窗创建失败时自动回退到原来的原生对话框，绝不卡死更新流程；
- 托盘进度与失败通知照常保留。

## 其它
- 无功能回归；更新逻辑（仍只指向你的 fork `kusesad-1122/deepseek-harness-desktop`）不变。
- CI 门禁全绿（122 项单测 + 4 项闭包检查）。

## 验证方式
1. 保持当前 2.0.6 不动，等下一版本发布；或手动到 Release 页下载 2.0.7 覆盖安装；
2. 安装后点托盘 **Check for Updates…**，当你的仓库出现比 2.0.7 更新的版本时，看到的就是新弹窗；也可以在 2.0.8 发布后用应用内更新实际走一遍「更新可用 → 下载进度 → 重启安装」全流程。

## What's new in 2.0.7
