## 紧急修复：切会话卡死/无响应

- 2.0.27 引入的统一存储层（`UnifiedDb` SQLite）在 `knowledge.ts:280/memory.ts:298 loadFromDisk()` 与 `addCard/applyOperations` 中同步 `await ensureUnifiedDb()+migrateFromFiles()`，切会话或首次加载大库时会阻塞主线程，导致无响应
- 现改为后台化：`loadFromDisk` 空库不再同步等待 SQLite，通过 `void (async()=>...)` 后台回填；`addCard/mirrorCard`、`applyOperations/mirrorToUnified` 与事件/候选写入全部改为 `void` 不阻塞文件提交，切会话立即返回
- `memory.ts:312` 后台回填时仅当内存仍空才覆盖，避免覆盖并发写入

## English

**Hotfix for freeze on session switch**

- UnifiedDb `ensureUnifiedDb()+migrate` was awaited in `loadFromDisk` and `addCard/applyOperations`, blocking the main thread on large stores and freezing session switches. Now all SQLite hydration/mirroring is backgrounded with `void`, session switch returns immediately.
