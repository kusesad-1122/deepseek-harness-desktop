# DSH Desktop v2.0.22 更新公告

**安装包**：[DSH-Desktop-2.0.22-x64-Setup.exe](https://github.com/kusesad-1122/deepseek-harness-desktop/releases/download/v2.0.22/DSH-Desktop-2.0.22-x64-Setup.exe)（Windows x64）
**SHA256**：`ff611faa96b4ffc64bc0ce6b7ba50fa80beffc4a3f976376d3fd73b08ba88716`

## 本版本重点

### 1. 项目内容改为右侧整页

- 左侧扩展项目栏始终保留，不再把项目内容塞进 300px 侧栏。
- 点击知识卡、每日热点新闻、知识图谱或专家风格模式后，内容在右侧主工作区以整页形式展示。
- 普通会话/工作区侧栏保持可见，便于切换会话。
- 点击“对话”或项目页返回按钮后，恢复原本的聊天主页面。

### 2. 自动修复升级后加载旧扩展的问题

- 修复 profile-local `node_modules/dsh-plugin-desktop` 物理副本遮挡新安装版本的问题。
- 启动时自动把旧副本替换成指向当前正式安装目录的 junction/symlink。
- Renderer memory bridge 改由 launcher patch 装配，不再依赖 profile bundle 中的旧子路径记录。

### 3. 延续 v2.0.21 项目能力

- 每日热点新闻与知识图谱继续保持独立数据和独立页面。
- 知识卡搜索、详情与删除仍在全页项目中可用。
- 专家风格模式仍支持平衡、严谨、创意、简洁、深度五种选择。

## 已知问题

- 本版本只发布 Windows x64 安装包。
- 当前 Windows 发布流程生成未做 Authenticode 签名的安装包；文件完整性以本页 SHA256 为准。

## English

**What's new in 2.0.22**

- Extension projects render as full main-workspace pages while both left navigation columns remain visible.
- Conversation restores the original chat page.
- Startup repairs stale profile-local desktop package copies after upgrades.

**Known issues**

- Windows x64 only; the installer is unsigned by Authenticode.
