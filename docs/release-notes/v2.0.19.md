## 🧠 思考强度全局默认 + 新闻板块上线

### 1. 任意自定义提供商的模型，思考强度下拉框**开箱即用**
之前只在 `qwen`、`kusesad` 等显式配置 `reasoningEfforts` 的提供商里能看到 `low / high / xhigh / max` 下拉框；现在**任意自定义提供商/模型**，只要模型支持推理，**不用再手动写 `reasoningEfforts`**，下拉框自动出现 `low / high / xhigh / max` 四档（以及关闭思考的 `off`）。
- 实现位置：上游 pi-ai 解析层 `resolveModelReasoning`（`deepseek-harness/packages/llm/llm-pi-ai/src/catalog.ts`），手写模型未声明 `reasoningEfforts` 时，默认给四档 + off。
- 保留：显式配置的优先，非推理模型（`reasoningEfforts: false`）不显示下拉。

### 2. 新闻路由上线
- `GET /dsh-desktop/knowledge/news` → 返回最近若干条知识卡片摘要，字段：`id, title, url?, summary?, publishedAt`。
- 客户端 `新闻与知识图谱` 板块从此不再显示“新闻服务尚未就绪”，直接展示最新知识卡摘要。

## 验证方式

1. 升级 2.0.19，重启 DSH Desktop；
2. **随便加个自定义提供商**（随便填个 OpenAI 兼容端点），点模型选择器 → 思考强度下拉框直接出现 `low / high / xhigh / max`（不用再手写配置）；
3. 升级 2.0.19，重启，**左侧扩展区 → 新闻与知识图谱** 板块直接显示最近的知识卡摘要（新闻源来自知识库最近条目，后续可接入真实新闻源）。
