## 🧠 记忆目标落地：左侧扩展区 + 知识卡/skill + 自动调取 + 全局推理档

这版是你要的「记忆目标」大版本。全局记忆（MEMORY/USER/CONVERSATIONS）已经打通，现在把**知识卡/skill 体系**和**左侧扩展区**做出来了。

### 1. 左侧扩展区（现有侧边栏之外的新最左列）

高级模式下，应用最左侧新增一列竖向板块（`extended | 侧边栏 | 会话 | 详情`）：

- **对话** —— 最近会话列表，点开即进；
- **知识卡** —— 知识库：列表 / 详情 / 删除（两段确认）/ 搜索 / 5 秒轮询；
- **新闻与知识图谱** —— 知识卡标签生成的 SVG 知识图谱 + 新闻（新闻源待 v2.0.18 补，当前优雅提示）；
- **专家风格模式** —— 本地风格选择器。

### 2. 知识卡 / skill（结构化 B）

- 字段：`标题 / 一句话结论 summary / 标签 tags / 来源会话 source / 时间`；
- 存储：`C:\Users\Administrator\.dsh\profiles\desktop\knowledge\knowledge.json`（原子写、去重、预算）；
- 命令：**`/distill`**（沉淀，DSH 命令名只允许 ASCII）——分析当前整段会话，一次有界 LLM 调用，沉淀成知识卡；
- `knowledge` 工具：agent 可主动读/写知识库；
- **自动调取**：每回合按关键词匹配知识卡，命中则注入 `<knowledge-context>` 段，下次同任务自动带出上次结论；
- HTTP 路由：`GET state/search/retrieve` + `POST cards/cards-update/cards-delete`（同源 + 4KB 上限）。

### 3. 全局思考强度默认

- 新增设置命名空间 `dsh-desktop-reasoning`（默认 `enabled=true, defaultEffort=high`）；
- **任何自定义提供商/模型**，只要未显式配置思考强度且模型支持该档位，就自动带上可调思考强度——不用再逐个手动加 `reasoningEfforts`。

### 4. 记忆必带（v2.0.16 延续）

任何预设/项目/会话，`memory` 工具和记忆提示词段都被强制放回。

## 验证方式

1. 升级 2.0.17，重启 DSH Desktop，切到**高级模式**；
2. 左侧出现扩展区：对话 / 知识卡 / 新闻与知识图谱 / 专家风格模式；
3. 聊完一个任务后输入 **`/distill`** → 知识卡写入 `knowledge\knowledge.json`；
4. 新会话做同任务 → 提示词自动带出上次知识卡结论；
5. 新增自定义提供商 → 无需手动配，思考强度自动可选。

## What's new in 2.0.17

- Left extended panel (new leftmost column outside the sidebar): 对话 / 知识卡 / 新闻与知识图谱 / 专家风格模式 sections.
- Knowledge card & skill system (structured B): `/distill` command + `knowledge` tool + auto-retrieval `<knowledge-context>` prompt injection; atomic JSON store with dedupe/budgets; same-origin HTTP routes.
- App-layer global reasoningEfforts default (namespace `dsh-desktop-reasoning`, default high) — any custom provider/model without explicit reasoningEfforts gets selectable effort automatically.
- Memory must-always-be-present continues from v2.0.16.
