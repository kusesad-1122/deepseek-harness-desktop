## 本版本重点

### 1. 内嵌浏览器（webview）支持

- 主窗口/高级窗口 `webPreferences` 开启 `webviewTag: true`，桌面插件的"内嵌浏览"视图升级为真实 Chromium 内嵌浏览器
- 效果：反爬站点直接渲染原页、需要登录的站点可在内嵌窗口里完成登录（cookie 持久化，独立 `persist:deepcode-news` 分区，不污染主会话）
- 兼容性兜底：插件侧自动检测——非 Electron 环境（或 webview 初始化失败）自动回退到同源代理 iframe，功能不倒退

### 2. 延续 2.0.28 的统一存储后台化

- SQLite 统一事实层全部镜像/回填保持后台执行，切会话零阻塞

## 已知问题

- 本版本只发布 Windows x64 安装包（未签名，完整性以本页 SHA256 为准）
- `sandbox` 渲染器下个别 Electron 版本对 `<webview>` 支持有限；如遇内嵌空白，阅读器会自动落到代理模式，正文与翻译不受影响

## English

**What's new in 2.0.29**

- Enabled `webviewTag` on both shell windows; the plugins' "embedded browse" view now runs a real Chromium guest — anti-scraping pages render directly and logins persist (dedicated `persist:deepcode-news` partition).
- Graceful fallback to the same-origin proxy iframe keeps extraction + translation working everywhere.
