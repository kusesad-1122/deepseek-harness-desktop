# DSH Desktop v2.0.5 更新公告

**安装包**：[DSH-Desktop-2.0.5-x64-Setup.exe](https://github.com/kusesad-1122/deepseek-harness-desktop/releases/download/v2.0.5/DSH-Desktop-2.0.5-x64-Setup.exe)（Windows x64）

## 🧠 记忆系统真正生效了

v2.0.3 加入的 `dsh-memory` 只有“存储 + 工具 + 快照注入”，需要模型主动调用才会写。这一版补齐了 Hermes 记忆架构最关键的 **L4 学习闭环**：**自动背景复习**。

### 现在它会自动做什么

- 每 **6 个用户回合**自动触发一次后台记忆复习（Hermes 同款节奏，默认 `reviewInterval` 可调）；
- 复习是**独立的、单次的有界 LLM 调用**：跑在回复之后、不阻塞你的下一句话、永不写入你的会话日志；
- 复习提示词直接移植 Hermes 的策展纪律：只收录「关于你的事实」和「你明确表达的行为期望」，明确拒绝琐事、一次性任务、临时报错、未验证的死路；
- 写盘仍走同一条受保护的路径：文件锁 → 漂移检测 → 字符预算（MEMORY.md 2200 / USER.md 1375）→ 原子写，**复习器自己也不能绕过限额**；
- 复习结果下一代会话进入系统提示词，所以新开对话问“你记得我什么”，模型能答出来。

### 新增 `/memory` 命令

在输入框输入 **`/memory`**，立刻看到：

- 当前 MEMORY.md / USER.md 的全部条目与用量（如 `38% — 840/2200 chars, 3 entries`）；
- 自动复习状态（已启用 / 上次复习多久前 / 每 N 回合一次）。

### 配置（`cordis.patch.yml` → `desktop-memory`）

```yaml
reviewEnabled: true
reviewInterval: 6        # 每 6 个用户回合复习一次
reviewCooldownMs: 60000  # 两次复习最短间隔
reviewTimeoutMs: 60000   # 单次复习硬超时
reviewMaxDigestChars: 8000
reviewMaxOutputTokens: 512
```

不想自动复习：把 `reviewEnabled` 设为 `false`，手动 `memory` 工具照常可用。

## 安装与验证方式

1. 应用内更新或下载上方安装包覆盖安装；
2. 正常用几轮（6 轮用户消息后触发第一次复习）；
3. 输入 `/memory` 查看条目，或新开会话直接问模型“你记得我什么”。

## What's new in 2.0.5

- Hermes-style automatic memory review (L4 learning loop): detached, bounded LLM curation every N user turns, writing only through the guarded MemoryStore path.
- New `/memory` command for instant visibility: live entries, char budgets, and review rhythm.
- Review policy ported from Hermes: user facts + behavioral expectations only; transient noise and one-off narratives are excluded.
