# DSH Desktop v2.0.9 更新公告

**安装包**：[DSH-Desktop-2.0.9-x64-Setup.exe](https://github.com/kusesad-1122/deepseek-harness-desktop/releases/download/v2.0.9/DSH-Desktop-2.0.9-x64-Setup.exe)（Windows x64）
**SHA256**：`待回填`

## 🔄 「检查更新」挪进 设置 → 关于

上个版本把「检查更新」按钮放在侧边栏底部，太挤、把旁边横向的文字都挤成竖排了。这版**把它撤掉**，改成你建议的位置：

- **设置 → 关于** 新增一个「关于」分区：
  - 简单介绍 DSH Desktop（DeepSeek Harness 桌面端）；
  - 显示**当前版本号**；
  - **「检查更新」按钮** —— 点击即手动检查，与托盘同一条流程，有新版弹 Hermes 风格更新窗，没有就提示已是最新；
  - 面板内实时显示 检查中 / 已是最新 / 发现新版本 / 下载进度。

- 侧边栏恢复清爽，不再占位；
- 自动检查（启动 60s 后 + 每 6 小时）不受影响，只查你的 fork `kusesad-1122/deepseek-harness-desktop`。

## 其它

- 无功能回归；CI 门禁全绿（122 单测 + 4 闭包检查）。

## 验证方式

1. 升级到 2.0.9；
2. 点「设置」→ 左侧出现「关于」，进去能看到版本号与「检查更新」按钮；
3. 侧边栏底部已无「检查更新」按钮。
