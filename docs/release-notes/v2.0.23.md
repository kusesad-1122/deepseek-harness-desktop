# DSH Desktop v2.0.23 更新公告

**安装包**：[DSH-Desktop-2.0.23-x64-Setup.exe](https://github.com/kusesad-1122/deepseek-harness-desktop/releases/download/v2.0.23/DSH-Desktop-2.0.23-x64-Setup.exe)（Windows x64）
**SHA256**：`9f23c192fe5aa5fce7961743c0982924f3eec22aa379f0d17f8d69ab603647f6`

## 本版本重点

### 1. 侧边栏与对话项目绑定

- 扩展面板首页现在显示五个独立项目：对话、知识卡、每日热点新闻、知识图谱、专家风格模式。
- 左侧工作区侧边栏**仅在选择「对话」时显示**；切换到其他项目时侧边栏自动隐藏。
- 其他项目在右侧主工作区以完整页面形式展示，不再塞进 300px 左栏。

### 2. 每日热点新闻改为 AI 专题 RSS 源

- 新闻数据源改为 Google News RSS（关键词：AI、人工智能、大模型），每天最多 10 条。
- 每条新闻包含标题、链接和封面图（来自 `<media:content>`）。
- 列表同时支持向原新闻页面跳转和打开完整简报。

### 3. 侧边栏与记忆桥接修复

- Agent 侧 memory/knowledge 插件改用明确的桌面 loopback Web 地址。
- 启动时自动把 profile 残留的旧物理副本替换成当前安装目录的 junction。
- 从旧版本升级后，profile 侧 `node_modules/dsh-plugin-desktop` 会自动指向新安装目录，不再手动维护。

## 升级方式

- 已安装用户：托盘菜单中的 Check for Updates；或直接下载安装包覆盖安装。

## 已知问题

- 本版本只发布 Windows x64 安装包。
- 当前 Windows 发布流程生成未做 Authenticode 签名的安装包；文件完整性以本页 SHA256 为准。
- 每日热点新闻依赖公共 RSS 源；源不可用时界面会显示明确的重试状态。

## English

**What's new in 2.0.23**

- The extension panel presents five projects: Conversation, Knowledge Cards, Daily Hot News, Knowledge Graph, and Expert Style.
- The upstream workspace sidebar is now shown only when "Conversation" is selected and is hidden for all other project views.
- Daily Hot News now loads 10 AI-focused headlines from Google News RSS, each with a cover image when available.
- Profile upgrade healing replaces stale physical desktop package copies with a current installation junction.
- Memory and knowledge agent bridges use an explicit desktop loopback route client.

**Known issues**

- Windows x64 only; the installer is unsigned by Authenticode.
- Daily Hot News depends on a public RSS feed and shows a retry state when the source is unavailable.
