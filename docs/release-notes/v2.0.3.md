## 本版本重点

### 1. 上游更新彻底断流，想跟才跟

- 应用内更新只检查本 fork 的 GitHub Releases，配置不完整时也不会隐式回落到官方 `dshdesktop.cn` 服务；
- 代码层上游（anywhere-labs）与 Harness 核心上游（deepseek-ai）均保持固定 pin，只有维护者主动 merge 时才跟进；
- 新增《上游跟进策略》双语文档：[docs/upstream-policy.md](../upstream-policy.md)，含手动跟进命令与复查清单。

### 2. 跨会话记忆（memory）

- 每个 profile 下新增 `memory/MEMORY.md`（agent 自己的笔记）与 `memory/USER.md`（用户画像），上限 2200 / 1375 字符；
- **冻结快照**：会话内写入立即原子落盘，当前会话系统提示词字节稳定，下次重启或切换 profile 后自动进入上下文；
- 新增模型工具 `memory`：add / replace / remove 与 `operations` 原子批量（按最终预算全有或全无）；超限、歧义匹配、外部改动都会返回带 `currentEntries` / `usage` 的可恢复提示；
- 写入安全：跨进程文件锁 + 原子替换；磁盘内容被外部改坏时先保存 `.bak` 快照再拒绝写入，绝不静默丢数据。

### 变更摘要

- 版本 2.0.2 → **2.0.3**
- `feat(updates)`: fork 更新通道隔离加固
- `feat(memory)`: 有界跨会话记忆（desktop-memory 插件）
- `docs`: 上游跟进策略、记忆配置说明

## 升级方式

- **2.0.2 用户**：托盘 → Check for Updates… 立即检查；或等待后台自动检查（启动约 1 分钟后，之后每 6 小时一次）；
- **全新安装**：直接下载安装包，双击按引导安装。

## 已知问题

- 本版本暂只发布 **Windows x64** 安装包；macOS 构建流水线尚未随本次发布提供，mac 用户请等待后续版本；
- 本地 Windows 全量测试存在一个既有的 POSIX 文件权限断言失败（`0600` vs `0666`），与本次改动无关；CI 发布门禁 `check:win-package` 已完整通过。

## English

**What's new in 2.0.3**

- In-app updates are pinned to this fork's GitHub Releases only; no implicit fallback to the upstream product service.
- New bounded cross-session memory: profile-scoped `MEMORY.md` / `USER.md`, frozen per-generation system-prompt snapshots, and a `memory` tool with add/replace/remove plus atomic batch operations.
- New upstream follow policy documentation for merging upstream code on demand.

**Known issues**

- Windows x64 installer only in this release.
- One pre-existing Windows-only POSIX mode assertion in the local full test suite; the CI packaging gate passes.
